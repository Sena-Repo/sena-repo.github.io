# Sena Repo 功能测试清单

这份清单用于发布前回归测试。测试前请准备至少一个本地游戏目录、一个 OpenList 游戏目录、一个可下载的压缩包，以及可选的 Steam 补丁和外部管理器环境。

## 环境准备

- [ ] 服务端已部署并运行（Docker 或直接启动）
- [ ] 客户端已安装并能访问服务端 IP:11451
- [ ] 游戏目录按当前扫描深度准备测试文件
- [ ] 至少配置一个本地目录或 OpenList 目录
- [ ] 需要测试刮削时，已准备对应 API 凭据
