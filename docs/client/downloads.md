# 下载与安装

## 下载游戏

1. 点击版本右侧「下载」按钮，在「下载游戏」窗口里确认下载版本和**安装目录**（默认使用客户端下载目录，也可以临时选择其他目录）
2. 下载进度在页面底部/通知栏显示
3. 下载完成后弹出操作选项：
   - **解压** — 解压到下载目录
   - **创建快捷方式**（Windows）
   - **导入 Steam**（Windows/Linux）
   - **打开文件夹** — 打开解压目标文件夹
4. 如果版本预设了解压密码，解压时自动使用；有密码但解压失败时弹窗提示

## 取消下载

下载弹窗中点击取消，终止当前下载任务并清理临时文件。

下载链路、aria2 回退与解压细节见 [下载与解压](/features/downloads)。
