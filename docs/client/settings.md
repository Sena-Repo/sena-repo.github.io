# 设置与备份

## 设置

进入「我的 → 设置」：

### 扫描设置（管理员）

- 查看和管理游戏库根目录
- 手动触发扫描
- 开关自动扫描、设置扫描间隔
- 调整目录结构（会社/游戏、仅游戏、扁平）
- 清空游戏库并重新扫描
- 管理 OpenList 服务器
- 配置刮削源、凭据、代理和批量字段来源（见下）
- 查看扫描 / 刮削进度

### 刮削设置（管理员）

刮削相关配置位于「设置 → 服务端 → 扫描设置」的「刮削源」区域：

- 配置 Bangumi / VNDB API Token
- 配置代理
- 设置批量自动刮削的字段来源规则
- NextMoe 模式下可选「补丁名称用 Steam 名称」：开启后补丁先解析 AppID、再取 Steam 商店名称，关闭则直接用 NextMoe 名称（取不到时自动回退）
- NextMoe 未绑定 OAuth 时，也可以继续使用服务端配置的 `SENA_NEXTMOE_API_KEY`

### 分类管理（管理员）

游戏库的「平台」分类不再固定为 PC / KRKR / Ty / ONS / 直装，可以在「设置 → 分类管理」中自定义：

- 添加、重命名、删除、拖拽排序分类；每个分类显示当前引用的版本数量
- **删除分类**时如果还有版本在使用，需要先选择替代分类（可以把版本转到「未分类」）
- **匹配规则**：点进分类编辑扫描识别规则。每条规则是「关键词」（文件名包含即命中）或「正则」（对完整文件名搜索，不区分大小写），支持拖拽排序；**分类顺序就是匹配优先级**（从上到下，首个命中即分类）
- 规则页顶部可以输入文件名做**测试匹配**，直接看到会归到哪个分类
- 内置分类带有初始规则（`[PC]`、`[KRKR]`/`[KR]`/`krkr`/`kirikiroid`、`[ONS]`、`[Ty]`/`[Ar]`/`tyranor`、`直装`/`安卓`/`.apk`），可以随意修改或删除
- 没有任何规则命中的文件归到系统分类「**未分类**」（不可重命名/删除，也不能配规则）；在筛选面板里可以直接筛出未分类的条目手动归类
- 「**按规则重新识别全部分类**」会用当前规则重刷所有版本（会覆盖手动修改过的分类）；平时的重新扫描只会给新文件和当前未分类的版本重新识别
- 分类列表会同步到游戏库筛选面板的「平台」chips 和编辑页的「修改平台」选项

### 下载设置

- 最大同时下载数（最高 10）
- 下载目录
- 下载限速（KB/s，0 为不限速）
- 快捷方式保存位置（Windows）

### 备份与恢复（管理员）

「设置 → 服务端 → 备份与恢复」：

- **导出备份** — 先选备份范围：**仅游戏库**（游戏、版本、标签、账号）、**仅补丁**（匹配规则 + 类型关键词）或**两个都备份**；选游戏库时可以勾选是否包含封面/背景/头像。生成后出现在下面的列表里，文件名里带范围标识（例如 `…-patch-….json`）
- **备份列表** — 显示服务端上已有的备份：文件名、大小、时间、是否含图片；每行可以「下载」（桌面端选保存位置，手机端存到应用目录并提示路径）或「删除」
- **导入备份** — 选择 zip/JSON 上传，导入前先选：恢复范围（全部 / 仅补丁规则 / 仅游戏库与账号）、已存在条目怎么处理（合并更新 / 清空重建）、同名图片怎么处理（跳过 / 覆盖）；导入完成后弹出各项统计

备份文件里有账号密码哈希与解压密码，请妥善保管。

### 显示与外观

封面大小、网格列数等显示选项在游戏库工具栏的「筛选与显示方式」面板里；主题色在「设置 → 美化」中调整。

### 客户端本地设置

登录/服务器选择界面右上角齿轮按钮，可修改：

- 游戏下载目录
- Steam `steamapps` 目录
- Steam 用户 ID

## 用户与通知

### 注册

在登录界面点击注册，提交后需等待管理员审批方可登录。也可以直接使用「鲲Galgame账号登录」：首次授权会自动创建待审批账号，并提示设置本机用户名。

### NextMoe 绑定

在「我的 → 个人信息」中可以查看和管理鲲Galgame账号绑定：

- **绑定** — 在系统浏览器完成授权后绑定，之后可用鲲Galgame账号免密登录本服务器
- **解除绑定** — 需要先设置本地密码；解绑后该鲲Galgame账号无法再登录本服务器
- 绑定后，单条目刮削会使用该账号自己的 NextMoe 授权

### 管理员审批

管理员可在：

- 通知页审批注册请求
- 「设置 → 用户管理」中审批或拒绝用户、授予或撤销管理员权限
- 「设置 → 用户管理」中为用户预先填写鲲Galgame ID，该用户首次用鲲Galgame登录时会自动完成绑定

审批完成后对应通知自动标记已读。

## Linux 触屏

Linux AppImage 针对 Wayland、X11、Gamescope、Bazzite 等环境做了触屏兼容处理，启动时自动优先 `GDK_BACKEND=wayland,x11`。

用终端启动可查看触屏诊断日志：

```bash
./Sena-Repo_Linux_v*.AppImage 2>&1 | tee sena-touch.log
```

正常情况下触摸屏幕会输出：

```
Sena Linux touch event: begin x=... y=...
Sena Linux touch event: update x=... y=...
```

如果有日志但界面无响应，请反馈日志中的 `backend` 和 `widget` 字段。

## 排障

### 点击服务器无反应

检查：
1. 服务器地址和端口是否填写正确
2. 是否选择了正确的 HTTP/HTTPS 协议
3. 服务端 `/api/health` 是否可访问
4. token 是否过期，必要时从服务器配置菜单重新登录

### 下载报 401

保存的登录 token 已失效。回到服务器选择界面，点击对应配置重新登录。

### OpenList 下载卡住

查看客户端日志中的 `download request` / `download redirect` 序列，判断卡在哪一跳：

- 卡在第一跳：客户端到 Sena 服务端不通
- 卡在第二跳：客户端访问不了 OpenList 地址（OpenList 地址必须客户端可访问）
- 卡在第三跳：CDN 对当前网络有限制

### Android 安装 APK 失败

报错类似 `Failed to find configured root that contains .../xxx.apk`，通常是安装来源路径不在应用可共享目录下。将下载目录设置到 Android 公共下载文件夹并确认已授予文件访问权限。
