# Steam 与补丁

## Steam 集成

Steam 集成功能仅在 Windows 和 Linux 上显示。

### 导入 Steam

下载解压完成后选择「导入 Steam」，客户端会将游戏以非 Steam 游戏的形式添加到 Steam 库，并尝试设置游戏图标。

需要在首次启动时正确填写 Steam `steamapps` 目录和 Steam 用户 ID。

## Steam 补丁注入

Steam 补丁页面分为「补丁注入」和「补丁配置」两个 Tab：前者在客户端执行扫描与注入，后者在服务端维护补丁匹配与类型关键词。

**补丁注入 Tab：**

1. 切换到该 Tab 时会自动刷新一次匹配结果
2. 点击「扫描 Steam 库」，客户端读取本地 `steamapps` 目录并发送游戏列表给服务端
3. 服务端根据 `patches.json` 匹配 AppID，顶部搜索框可按游戏 / 补丁关键词过滤
4. 匹配到的游戏会显示可用补丁列表
5. 补丁规则已配置时显示「注入」，点击后下载补丁压缩包并解压到对应游戏目录；规则未配置时按钮显示「规则待配置」，可以点「跳转配置」直达「补丁配置」里的对应行
6. 注入时如果压缩包需要解压密码，会提示输入密码重试（也可以在下载管理器中重试）

补丁下载走的是签名直链（`POST /api/steam/patches/{key}/link` 取一次带时效的 URL），因此和游戏下载共用同一条管线：优先交给内置 aria2 多连接下载，失败再退回分片/流式；网盘上的补丁还会按来源类型用浏览器 UA 和分片降级重试。链接过期时客户端会自动换一条新的继续下。

**补丁配置 Tab（管理员）：**

- 顶部搜索框可按补丁 / AppID 过滤
- 查看和编辑 `patches.json` 中的补丁条目，每行可以展开查看详情
- 编辑弹窗分为「元数据 / 配置」两个分段，可以分别保存；弹窗里提供「打开目标文件夹」
- 手动触发补丁扫描时会先选择扫描模式，并显示扫描进度：
  - **合并刷新** — 保留已配置的规则、名称和锁定，补新文件、删丢失文件
  - **仅清空元数据** — 保留规则、状态与锁定，重新解析 AppID / 名称 / 标签 / 类型
  - **清空重扫** — 丢弃全部已配置信息，完全按磁盘重建
- 通过右上角「关键词匹配」编辑类型识别关键词
- 每行右侧可以**锁定元数据**：锁上后自动扫描与「重新刮削 AppID」都不会改动这条的 AppID、游戏名、标签、类型与注入规则（文件大小、来源路径这类文件事实仍会随扫描更新），再点一次解锁
- 「重新刮削」只解析并填充 AppID / 游戏名，点「保存元数据」后才写入；「批量刮削 ID」会直接写入

补丁索引、AppID 识别规则和备份方式见 [Steam 补丁注入](/features/steam-patch)。
