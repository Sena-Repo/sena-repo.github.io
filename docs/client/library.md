# 游戏库与详情

进入游戏库后可以浏览、搜索、筛选游戏，并进入详情页查看版本信息；管理员还能编辑元数据和按版本维护下载内容。

## 游戏库浏览

- **网格/列表视图切换** — 在上方工具栏「筛选与显示方式」面板里切换
- **搜索** — 顶部搜索栏实时过滤
- **排序** — 按导入时间、名称、别名、会社、游玩时长排序
- **筛选** — 按标签、平台筛选；多条件可叠加（平台分类可在「设置 → 分类管理」中自定义）
- **批量操作** — 多选后可以批量删除、打标签、触发批量刮削，或批量**锁定/解锁元数据**（已锁定的条目会被批量刮削跳过）
- **显示相关** — 封面大小、网格列数等显示选项在工具栏的「筛选与显示方式」面板里
- **下拉刷新** — 列表顶部下拉重新加载

## 游戏详情

点击游戏进入详情页，显示封面、背景图、简介、标签、版本列表。下载入口和完成后的操作见 [下载与安装](/client/downloads)。

## 元数据编辑（管理员）

游戏详情页右上角菜单可进入编辑界面：

- 修改名称、别名、会社、简介、发行日期等文字字段
- 修改封面/背景图（上传本地文件或粘贴 URL）
- 按版本修改平台分类（PC / KRKR 等）
- 按版本设置解压密码
- 按版本移动到其他游戏条目
- 「平均时长」为只读字段，可手动清除，不能直接编辑

编辑页顶部可以「锁定元数据」：锁定后该条目的元数据、封面、标签与版本信息将不可修改，需要解锁后才能编辑；游戏库多选也可以批量锁定/解锁。
