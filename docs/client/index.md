# Sena Repo 客户端使用说明书

Sena Repo 客户端用于连接 Sena Repo 服务端，浏览游戏库、下载并解压游戏、导入 Steam 非 Steam 游戏、推送到外部管理器，以及注入 Steam 补丁。当前支持 Windows、Android 和 Linux。

## 安装

从 [GitHub Releases](https://github.com/404-GCross/Sena-Repo/releases) 下载对应平台客户端：

| 平台 | 文件 | 说明 |
|------|------|------|
| Windows | `.exe` 安装包 / `.zip` 便携版 | 推荐安装版；便携版解压后直接运行 |
| Android | `.apk` | 需要授予文件访问权限 |
| Linux | `.AppImage` | 适合桌面 Linux / 掌机系统 |

Windows、Linux 和 Android 客户端均内置 7zip-zstd 解压组件；下载优先使用内置 aria2，必要时回退到 Dart 下载流程。Android 不显示 Steam 相关功能。

## 首次启动

客户端首次启动时会弹出免责声明，同意后进入本机设置：

- **游戏下载目录** — 下载压缩包和解压后文件的保存位置
- **Steam `steamapps` 目录** — 用于 Steam 补丁匹配，填写 Steam 库的 `steamapps` 文件夹路径
- **Steam 用户 ID** — Steam 好友代码，也可在 Steam 安装目录 `userdata` 文件夹中找到纯数字目录名

这些设置保存在当前设备，不会写入服务端。之后可在登录 / 服务器选择界面右上角齿轮按钮修改，或在「设置 → 下载设置」中更改。

## 连接服务器

### 添加服务器

在服务器选择界面点击「添加服务器」，进入二级界面填写：

- 配置名称
- 服务器地址（IP 或域名）
- 端口（默认 `11451`）
- 是否使用 HTTPS
- 用户名和密码

保存后会作为一条服务器配置显示在列表中。每条配置右侧的三点菜单可编辑或删除；编辑服务器地址、协议、用户名或密码后，相当于重新登录该配置。

### 自动登录

客户端启动时会优先尝试自动登录上次使用的服务器配置，并请求 `/api/auth/profile/me` 检查保存的 token 是否仍然有效：

- token 有效：直接进入游戏库
- token 过期或服务端重置：提示重新登录或进入初始化流程
- 连接异常：弹窗提示连接失败，不会静默失败

### 退出登录

在「我的」界面点击「退出登录」，会回到服务器选择界面。退出只清除当前激活会话，不删除已保存的服务器配置。

## 首次初始化服务端

连接到未初始化的服务端时，客户端会进入初始化向导：

1. **创建管理员**：填写首个管理员用户名和密码。
2. **配置目录与刮削**：添加游戏库目录、Steam 补丁目录、批量刮削字段来源、自动扫描开关与扫描间隔。
3. **本地配置（可选）**：确认当前客户端的下载目录和 Steam 目录。

游戏库目录和 Steam 补丁目录都支持本地路径或 OpenList 文件源。刮削源当前已支持 Hikarinagi、VNDB Kana、Bangumi 和 Steam；NextMoe 支持正在开发，文档中按开发中能力保留。

初始化完成后，服务端会在后台自动触发首次扫描和刮削。

## 游戏库浏览

进入游戏库后：

- **网格 / 列表视图切换** — 右上角图标切换
- **搜索** — 顶部搜索栏实时过滤
- **排序** — 按导入时间、名称、会社、游玩时长排序
- **筛选** — 按标签、平台筛选；多条件可叠加
- **下拉刷新** — 列表顶部下拉重新加载
- **批量操作** — 多选后可批量删除、打标签或触发批量刮削

## 游戏详情与下载

点击游戏进入详情页，显示封面、背景图、简介、标签、元数据 ID 和版本列表。

### 下载游戏

1. 在版本列表中点击下载。
2. 客户端请求服务端生成短期签名下载链接。
3. 本地文件源由 Sena 服务端返回文件流；OpenList 文件源会继续跳转到 OpenList / 网盘 / CDN。
4. 客户端优先使用 aria2 下载；失败或不适用时回退到 Dart 下载。
5. 下载完成后调用内置 7zip-zstd 解压。

下载任务支持暂停、继续、取消、并发数限制和全局限速。OpenList 下载流量默认直连 OpenList / CDN，不经过 Sena 服务端代理。

### 完成后操作

下载解压完成后，桌面端可执行：

- 打开目标文件夹
- 创建快捷方式（Windows）
- 导入 Steam（Windows / Linux）
- 推送到 LunaBox 或 ReinaManager 下载入库

推送到外部管理器会生成 `lunabox://install` 或 `reinamanager://install` 协议链接。目标管理器需要已经安装并注册协议；带解压密码的版本暂不支持推送。

## 元数据编辑

游戏详情页右上角菜单可进入编辑界面：

- 修改名称、会社、开发商、简介、发行日期等字段
- 修改封面 / 背景图（上传本地文件或粘贴 URL）
- 维护 VNDB、Bangumi、Steam、Hikarinagi 等外部 ID
- 按版本修改平台分类（PC / KRKR / Tyranor / ONS / Android 直装等）
- 按版本设置解压密码
- 按版本移动到其他游戏条目

### 刮削

在编辑页可以选择刮削源并输入关键词搜索。服务端返回候选结果后，客户端会展示当前字段与刮削字段的对比，只有选中的字段会被应用。

Hikarinagi 凭据、VNDB Token、Bangumi Token、代理、刮削源顺序和启用状态可在「刮削设置」中配置。

## Steam 集成

Steam 集成功能仅在 Windows 和 Linux 上显示。

下载解压完成后选择「导入 Steam」，客户端会将游戏以非 Steam 游戏的形式添加到 Steam 库，并尝试设置游戏图标。需要提前正确填写 Steam `steamapps` 目录和 Steam 用户 ID。

## Steam 补丁注入

Steam 补丁页面分为「客户端」和「服务端」两个 Tab。

**客户端 Tab：**

1. 点击「扫描 Steam 库」，客户端读取本地 `steamapps` 目录并发送游戏列表给服务端。
2. 服务端根据 `patches.json` 按 AppID 匹配补丁。
3. 匹配到的游戏显示可用补丁列表。
4. 点击「注入」下载补丁压缩包并解压到对应游戏目录。

**服务端 Tab（管理员）：**

- 查看和编辑 `patches.json` 中的补丁条目
- 手动触发补丁扫描
- 编辑类型识别关键词
- 维护 `patch_dir` / `target_dir` 等注入参数

## 设置

进入「我的 → 设置」可管理以下内容：

| 设置 | 说明 |
|------|------|
| 扫描设置 | 管理游戏库根目录、Steam 补丁目录、OpenList 服务器、目录结构和自动扫描 |
| 刮削设置 | 管理 Hikarinagi / VNDB / Bangumi / Steam 的启用状态、顺序、凭据和代理 |
| 下载设置 | 管理最大同时下载数、下载目录、限速和快捷方式保存位置 |
| 显示设置 | 管理封面大小、外观偏好和主题色 |
| 用户管理 | 管理注册审批、管理员权限和用户状态 |

## 用户与通知

### 注册

在登录界面点击注册，提交后需等待管理员审批方可登录。

### 管理员审批

管理员可在通知页审批注册请求，也可在「设置 → 用户管理」中审批或拒绝用户、授予或撤销管理员权限。权限变更后目标用户需要重新登录才能刷新权限信息。

## Linux 触屏

Linux AppImage 针对 Wayland、X11、Gamescope、Bazzite 等环境做了触屏兼容处理，启动时自动优先 `GDK_BACKEND=wayland,x11`。

用终端启动可查看触屏诊断日志：

```bash
./Sena-Repo_Linux_v*.AppImage 2>&1 | tee sena-touch.log
```

正常情况下触摸屏幕会输出：

```text
Sena Linux touch event: begin x=... y=...
Sena Linux touch event: update x=... y=...
```

如果有日志但界面无响应，请反馈日志中的 `backend` 和 `widget` 字段。

## 排障

### 点击服务器无反应

检查：

1. 服务器地址和端口是否填写正确。
2. 是否选择了正确的 HTTP / HTTPS 协议。
3. 服务端 `/api/health` 是否可访问。
4. token 是否过期，必要时从服务器配置菜单重新登录。

### 下载报 401

保存的登录 token 已失效。回到服务器选择界面，点击对应配置重新登录。

### OpenList 下载卡住

查看客户端日志中的 `download request` / `download redirect` / `aria2 download` 序列，判断卡在哪一跳：

- 卡在第一跳：客户端到 Sena 服务端不通
- 卡在第二跳：客户端访问不了 OpenList 地址
- 卡在第三跳：客户端访问网盘 / CDN 不通或被 CDN 限制

### Android 安装 APK 失败

报错类似 `Failed to find configured root that contains .../xxx.apk`，通常是安装来源路径不在应用可共享目录下。将下载目录设置到 Android 公共下载文件夹，并确认已授予文件访问权限。
