# 功能特性

除了游戏库浏览与下载，Sena Repo 还提供这些能力：

- [元数据刮削](/features/metadata-scraping) — VNDB / Bangumi / Steam / Hikarinagi / NextMoe 多源搜索，逐字段对比，自动填充别名与游玩时长
- [Steam 补丁注入](/features/steam-patch) — 补丁索引、AppID 匹配、下载注入与元数据锁定
- [下载与解压](/features/downloads) — 签名直链、OpenList 直连、aria2 多连接下载与 7zip-zstd 解压

相关页面：

- [推送下载](/push/) — 生成 LunaBox / ReinaManager 协议链接
- [文件源接入](/server/sources) — 本地目录与 OpenList
- [Steam 与补丁（客户端操作）](/client/steam)
