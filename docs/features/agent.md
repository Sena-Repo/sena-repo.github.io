# 智能体扫描与刮削

智能体是服务端的可选能力，默认关闭，仅管理员能够配置、测试、运行任务和查看结果。普通用户继续使用已整理的游戏资料与补丁配置，匿名请求不能调用智能体。

## 配置入口

进入「设置 → 服务端 → 智能体」。首次初始化在创建管理员、配置目录与刮削源后，自动登录管理员并进入可跳过的第 4 步；配置失败不撤销已经完成的基础初始化。

游戏识别、分类、封面选择和补丁分析共用**一个模型**。提供商预设只是预填地址与协议，支持 OpenAI、Anthropic、Google Gemini、DeepSeek、通义千问、智谱、OpenRouter、Ollama、LM Studio、vLLM 和自定义服务。

可使用的接口协议为 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、Gemini 原生与 Ollama 原生。填写模型 ID 后保存并测试工具调用能力；不支持模型列表的服务可以直接手填 ID。只有模型本身支持图片输入时才开启图片分析。

模型连接由 **Sena 服务端**发起：`localhost` 指服务端所在环境，Docker 部署时指容器内部。局域网模型需要填写服务器能够访问的地址。

## 智能体独立代理

- **直连**：默认，忽略服务端通用代理和代理环境变量。
- **继承服务端代理**：使用服务端当前代理配置。
- **自定义代理**：HTTP / SOCKS5 地址，可设置独立用户名和密码。

模型列表、连接测试和推理请求共用此设置；智能体调用的普通刮削源及 OpenList 保留各自的网络配置。API Key 与代理密码在服务端加密保存，读取配置时不返回明文。地址与协议未变时，编辑留空保留已有凭据；更换目标服务或代理地址后需重新填写对应凭据，避免把旧密钥发送到新服务。

## 手动与定时扫描

手动扫描游戏库、补丁库以及批量刮削时，可选择「常规扫描」或「智能体扫描」，勾选「记住此选择，下次不再询问」后直接使用对应默认方式。游戏与补丁分别记忆，也可在智能体的「扫描默认项」恢复询问。

「清空并重扫」同样支持选择扫描方式，再单独确认清理操作。只清理可重建的扫描记录，保留手动条目、名称锁定和元数据锁定条目，不删除原文件。智能体任务会在检查配置、权限与扫描锁后执行清理；已完成清理的任务再次重试时不会重复清空。

总开关关闭或模型未配置时，智能体选项不可用；已记住的智能体默认方式回退为常规方式。定时任务跟随扫描设置中的计划，不弹窗，游戏和补丁可分别选择处理方式。

关闭智能体会取消排队任务、停止后续模型调用，保留已完成结果。正在发送的请求可能仍产生费用。未开启时，普通扫描、手动刮削及补丁使用无需模型。

## 游戏识别与偏好

智能扫描直接分析指定库中的相对目录、文件名、大小和压缩包清单，不要求固定的会社／游戏层级；识别时可读取有限大小的说明文本，并查询已经启用的刮削源。忽略路径与锁定记录仍生效。

现有来源顺序作为查询优先级，NextMoe 独占模式保持不变。模型从真实候选中选择，不允许写入任意作品 ID 或图片地址。游戏版本自动归组，已存在且冲突的归组交给管理员处理，不移动或删除原文件。

可配置中文或原文名称优先、中文或原版封面优先、竖版与高清偏好、简介翻译、只补缺失或更新未锁定资料，以及自然语言补充要求。候选封面的语言与版本资料优先作为依据；允许视觉分析时，相关候选图片会发送至所选模型。没有可靠中文封面时遵循回退策略。

现有平台分类可供模型选择。规则未命中或模型无法确认平台时默认归入 PC；自动兜底 PC 与人工确认 PC 分开记录，智能体可继续补判自动兜底版本，保留人工或已确认分类。尚未确认的平台不会因上次元数据刮削成功而永久跳过补判。内容标签来自真实刮削资料。散装游戏可建立目录条目，但不会生成虚假的压缩包下载版本。

## 补丁配置

「使用 Steam 名称」默认开启。匹配到经过验证的 Steam ID 后查询名称；获取不到时使用其他已确认来源。这只影响关联游戏名称，不重命名补丁文件。

智能体分析压缩包清单和小型 TXT / Markdown 说明，生成 `patch_dir`、`target_dir`。只有源目录存在、路径合法、具有实际安装说明依据且属于复制式补丁时，才自动保存明确配置。已有已确认 manifest 和锁定信息受到保护。

安装器、脚本、多分支或缺少说明的补丁可识别关联游戏，但保持待配置。保存 manifest 不会立即安装，客户端仍执行目录与压缩包安全校验。OpenList 压缩包分析受下载上限限制，设为 0 可禁止智能体为分析下载远程压缩包。

## 批量处理与兜底

选择一次范围即可后台运行，不逐个弹窗。智能体优先，常规扫描及刮削补齐尚未确定的内容。任务总请求次数和总 Token 上限是可选配置，默认 `0` 表示不限制；由管理员填写正数后才启用对应上限。旧版已经保存的上限仍会保留，需要在设置中主动改为 `0` 才能取消。单次请求超时与单条目的分析轮数可在「请求与分析设置」中调整。

达到限制时标记为「预算回退」，不代表作品无法匹配；模型异常、结果校验失败、资料源异常、未获得可验证匹配也会分别显示。识别成功的记录不再统一附带“未确定内容交给常规扫描”的提示。

智能体扫描统一显示在「设置 → 扫描设置 → 扫描进度」区域。从该页启动后留在当前页，点击进度卡片或「查看详情」即可进入对应任务；离开页面再返回会自动读取后台状态。进度区右侧的「智能体历史」用于查看其他智能体任务，智能体设置页右上角也保留历史入口。退出进度页面不会取消后台任务。

任务记录提供状态、请求次数、token 用量、结果来源、判断依据、停止和重试。目录准备阶段会显示已遍历目录、条目及候选文件数；这一阶段尚未调用模型，因此请求次数可能为 `0`，尤其 OpenList 大型目录需要等待清单完成。未变化且已有成功结果的内容复用缓存；服务端重启后未完成任务标记为中断，不伪装成已经完成。一次只运行一个智能体任务，扫描和恢复操作互斥。

## 数据与备份

服务启动时自动创建智能体配置、任务及结果表，无需手动回填。已有安装默认关闭功能。

游戏库备份包含模型非敏感配置与偏好，**不包含模型 API Key 和代理认证信息**。恢复后智能体保持关闭，需管理员重新填写凭据并启用。历史任务记录不随备份迁移。

模型测试会真实调用所选服务，可能产生费用。自动测试使用模拟模型与资料源，不代表每个第三方提供商和模型版本都完成了真实服务验收。
